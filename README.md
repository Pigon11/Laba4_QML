## Описание программы
Программа представляет собой простое графическое приложение-рисовалку (Paint), написанное с использованием гибридного подхода: интерфейс реализован на QML (frontend), а логика — на Python (backend). 

**Как это работает:**
1. Пользователь рисует на холсте (`Canvas`) в QML.
2. При движении мыши холст помечается как «изменённый» (свойство `dirty = true`).
3. В QML работает `Timer`, который срабатывает каждые 5 секунд.
4. Если холст был изменён, таймер вызывает метод `toDataURL("image/png")`, который превращает рисунок в строку формата base64.
5. Эта строка передаётся в Python через вызов `_backend.saveImage(...)`.
6. Python-метод `saveImage` (в классе `Interface`) декодирует base64 обратно в картинку (`QImage`), накладывает её на белый фон (чтобы убрать прозрачность) и сохраняет в папку `saves` с уникальным именем (текущая дата и время).

## Структура проекта
- `main.py` — запуск приложения, класс `Interface` с логикой сохранения файлов.
- `mainWindow.qml` — главное окно, интерфейс, холст `Canvas` и таймер.
- `Circle.qml` — вспомогательный компонент (кнопка выбора толщины кисти).
- `Square.qml` — вспомогательный компонент (кнопка выбора цвета).

## Технологии
- Python 3.8+
- PyQt5 (PyQt5.QtQml, PyQt5.QtGui)
- QML (Qt Quick)

## Запуск
1. Установите зависимости:
```bash
pip install PyQt5
```
2. Запустите приложение:
```bash
python main.py
```
3. Нарисуйте что-нибудь на холсте и подождите 5 секунд — рисунок автоматически сохранится в папку `saves`.
